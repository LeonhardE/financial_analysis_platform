# Portfolio trust configuration foundation

## Summary

- Add explicit offline profile v4 and Portfolio trust compilation, with independent Hub trust and Web owner invoker selections.
- Bind five fixed nonsecret settings and exact service invokers to the selected Portfolio and Hub identities; require explicit source adoption before managed consumption.
- Admit the existing Portfolio service to guarded image release while keeping its trigger deployment switch off and ordinary Terraform execution inactive.
