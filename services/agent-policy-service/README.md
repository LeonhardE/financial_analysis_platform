# Retired independent Policy target

The unused standalone Policy service and its dedicated deployment configuration
have been removed. This directory retains historical protocol/operation references
only; it has no application, dependencies, image or deployable target.

Personal Agent-owned credentials use the existing
[Agent Hub](../agent-hub-service/README.md), Web and storage. No additional Policy
project, key-release service or Confidential VM is required. The terminal registry
record prevents accidental reactivation. This source retirement does not destroy
cloud resources, historical ciphertext or revocation records.
